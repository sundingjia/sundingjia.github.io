【具体数学】汉诺塔

【具体数学】汉诺塔

具体数学学习笔记 1

题目描述

汉诺塔由三根柱子（分别用 A、B、C 表示）和 nnn 个大小互不相同的空心盘子组成。一开始 nnn 个盘子都摞在柱子 A 上，大的在下面，小的在上面，形成了一个塔状的锥形体。

对汉诺塔的一次合法的操作是指：从一根柱子的最上层拿一个盘子放到另一根柱子的最上层，同时要保证被移动的盘子一定放在比它更大的盘子上面（如果移动到空柱子上就不需要满足这个要求）。我们可以用两个字母来描述一次操作：第一个字母代表起始柱子，第二个字母代表目标柱子。例如，AB 就是把柱子 A 最上面的那个盘子移到柱子B。汉诺塔的游戏目标是将所有的盘子从柱子 A 移动到柱子 B 或柱子 C 上面。

问将 A 柱上整个塔移动到另一个柱上，最少需要移动多少步。

sol

初步探究

研究这个问题，有一个通用的步骤。

  1. 研究小规模问题。
  • 111 个盘子只用移动一下。
  • 222 个盘子只用移动 333 次。
  • 333 个盘子移动 777 下。具体方案非常建议自己手磨。
  1. 接下来，应当引入适当记号，进行命名和求解。

我们设 TnT_nTn​ 为 nnn 个盘子时的方案数。

显然：

  • T1=1T_1=1T1​=1
  • T2=3T_2=3T2​=3
  • T3=7T_3=7T3​=7

那么，问题来了。

Tn=??T_n=??Tn​=??

我们回想一下 n=3n=3n=3 时怎么移动。（没印象的建议重新手磨）

整体过程分为 333 个阶段：

  1. 把前两个盘子移动到 B 柱上。

  2. 将第三个盘子移到 C 柱上。

  3. 将前两个盘子移到 C 柱上。

推广到任意数，我们就能得到一个结论。

Tn≤2×Tn−1+1    n≥1T_n \le 2 \times T_{n-1} + 1 \ \ \ \ n \ge 1 Tn​≤2×Tn−1​+1    n≥1

Tn=0       n=0T_n = 0 \ \ \ \ \ \ \ n = 0 Tn​=0       n=0

同样的，想移动最后一根盘子，至少把前几个盘子挪走，需要 Tn−1T_{n-1}Tn−1​ 次操作。

如果我们不太精明，第 nnn 个盘子可能移动多次。

前几个盘子再移回去有是 Tn−1T_{n-1}Tn−1​ 次。

所以又得到了一个结论

Tn≥2×Tn−1+1    n≥1T_n \ge 2 \times T_{n-1} + 1 \ \ \ \ n \ge 1 Tn​≥2×Tn−1​+1    n≥1

Tn=0       n=0T_n = 0 \ \ \ \ \ \ \ n = 0 Tn​=0       n=0

两者取交集：

Tn=2×Tn−1+1    n≥1T_n = 2 \times T_{n-1} + 1 \ \ \ \ n \ge 1 Tn​=2×Tn−1​+1    n≥1

Tn=0       n=0T_n = 0 \ \ \ \ \ \ \ n = 0 Tn​=0       n=0

但是这么算，你会飞起来。

我们考虑化简。

证明见后。

更吃注意力

我们注意到 式子两边同时加一会使处理更加简洁

Tn+1=2×Tn−1+2    n≥1T_n + 1 = 2 \times T_{n-1} + 2 \ \ \ \ n \ge 1 Tn​+1=2×Tn−1​+2    n≥1

Tn+1=1       n=0T_n + 1 = 1 \ \ \ \ \ \ \ n = 0 Tn​+1=1       n=0

我们令 Un=Tn+1U_n=T_n+1Un​=Tn​+1

然后我们有了一组式子：

Un=2×Un−1    n≥1U_n = 2 \times U_{n-1} \ \ \ \ n \ge 1 Un​=2×Un−1​    n≥1

Un=1       n=0U_n = 1 \ \ \ \ \ \ \ n = 0 Un​=1       n=0

然后这个东西就相当简单，

易得

Un=2n       n≥0U_n=2^n \ \ \ \ \ \ \ n \ge 0 Un​=2n       n≥0

代回原式

Tn=2n−1       n≥0T_n = 2^n - 1 \ \ \ \ \ \ \ n \ge 0 Tn​=2n−1       n≥0

证明

对于 n=0n=0n=0 显然成立。

假设这个对于 n−1n-1n−1 成立。

所以

Tn=2×Tn−1+1=2×(2n−1−1)+1=2n−1T_n=2 \times T_{n-1} + 1 = 2 \times (2^{n-1}-1) + 1 = 2^n-1 Tn​=2×Tn−1​+1=2×(2n−1−1)+1=2n−1

所以对于 nnn 成立。

证明完了。
